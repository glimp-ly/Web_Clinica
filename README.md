# Web para Clinica "El Centenario"

Este repositorio es donde se aloja el codigo fuente de tanto el frontend como el backend de la plataforma web de la clinica "El Centenario"

## Estructura

- `frontend_clinica/`: todo el frontend (17 vistas `*.html`, `css/`, `js/`, `img/`).
  Servir local con: `cd frontend_clinica && python3 -m http.server 8090`
- Paleta base: azules `#263193 #0077b6 #033076`, verdes `#029d56 #28a745 #176428`,
  error `#d93025`, dark `#121212 #1e1e1e #e0e0e0 #4da3ff`.
  Header/footer y dark-mode unificados vía `css/styles.css` + `js/layout.js`.
